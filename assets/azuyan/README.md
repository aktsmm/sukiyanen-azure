## 使い方のヒント

- スライドの表紙に置くなら背景透過の `azuyan.png` が使いやすいです
- 印刷物や 1 色刷りには SVG のモノクロ版をどうぞ
- 黒っぽい背景のスライドでは `azuyan-for-dark-bg.svg` を使うと目がつぶれません
