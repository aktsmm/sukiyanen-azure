# 登壇者・資料作成者の方へ

すきやねん Azure!! で登壇いただくみなさま、資料をご準備いただくみなさまへのご案内です。

## どんな場か

すきやねん Azure!! は、関西の Microsoft / Azure ユーザーコミュニティです。エンジニアからインフラ・ビジネス層まで幅広い方が集まるオフラインの会で、初心者の参加者も多いです。

発表は「完璧な資料」より「実体験・ハマりどころ・やってみた感」が刺さる場です。デモ重視でも全然 OK です。録画・配信もないので、初めての登壇にもうってつけです。

ひとつお願いがあるとしたら、「聴いた人が 1 つ持ち帰れるもの」を意識してもらえると嬉しいです。難しいトピックでも、「こういう考え方があるんや」「今度触ってみよう」と思ってもらえれば十分です。

## セッションの枠

- セッション時間は **20〜30 分**です（LT 枠を設ける回もあります）
- ご希望があればお気軽にご相談ください
- ハッシュタグは **#すきやねんAzure** です

## 事前にいただきたい情報

告知の準備のために、以下を教えていただけると助かります。

- **セッションタイトル**（仮でも OK）
- **スピーカー名**（X ハンドルや表記の希望があれば）
- **セッション概要**（2〜3 行程度、可能であれば）

## 資料の共有をお願いします

- できれば **当日まで** に、運営チャットでも個別のご連絡でも構いませんので、資料を共有いただけると助かります
- 形式は問いません
  - PDF / PowerPoint ファイル
  - ブログ記事
  - Docswell / Speaker Deck などスライド共有サービスの URL
- いただいた資料は、**参加者へお送りするお礼メール** でまとめて共有します
- 資料の公開が難しい場合は、その旨ご連絡いただければ大丈夫です。無理に出していただく必要はありません

事前レビューは必須ではありません。可能なら開催 1 週間前、難しければ開催後 1〜2 日後の共有でも構いません。

## 資料づくりのお願い

- 参加者には **初心者の方も多く** いらっしゃいます。**「これだけ持ち帰ってほしい」がひと目で伝わるスライドを 1 枚** 入れていただけると嬉しいです
- 内容が難しめのセッションでは、途中に息継ぎポイントを作るのがおすすめです
  - 休憩スライド
  - クイズスライド（例：「これ、何の画面かわかりますか？」）
  - Q&A スライド
- 「もっと突っ込んだ話が聞きたい」という方には、**ぜひ懇親会で！** と誘導いただけると、いろんな層の方が楽しめる会になります
