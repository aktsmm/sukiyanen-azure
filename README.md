# すきやねん Azure!!

<img src="assets/azuyan/azuyan.png" alt="アズヤン" width="180" align="right">

**すきやねん Azure!!** は、関西で開催している Microsoft / Azure のユーザーコミュニティです。

エンジニアからインフラ・ビジネス層まで幅広い方が集まるオフラインの会で、初心者の参加者もたくさんいます。録画・配信はしていないので、初めての登壇にもうってつけの場です。

このリポジトリは、**登壇者・資料作成者向けのご案内**と、**マスコットキャラクター「アズヤン」の画像素材**を公開しています。

- 登壇希望フォーム: <https://aka.ms/SukiyanenSpeaker>
- ハッシュタグ: **#すきやねんAzure**

## 登壇者募集中です

すきやねん Azure!! は、**登壇者をいつでも募集しています**。

- セッション時間は **20〜30 分**（LT 枠を用意する回もあります）
- 「完璧な資料」より「実体験・ハマりどころ・やってみた感」が刺さる場です
- デモ中心でも大歓迎
- 内容のご相談は歓迎です。まずはお気軽にどうぞ

エントリーはこちらから 👉 <https://aka.ms/SukiyanenSpeaker>

詳しくは [登壇者・資料作成者の方へ](docs/for-speakers.md) をご覧ください。

## アズヤンについて

「アズヤン」はすきやねん Azure!! のマスコットキャラクターです。

すきやねん Azure!! での登壇資料や関連する発信にお使いいただけます。利用条件は [assets/azuyan/README.md](assets/azuyan/README.md) をご確認ください。

各回のお申し込みは [MICUG（Microsoft ユーザーグループ）](https://micug.jp/) のイベントページから受け付けています。最新の開催情報は [開催回一覧](docs/events.md) をご覧ください。
